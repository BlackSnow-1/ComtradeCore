# ComtradeCore 1.3.0.1

本版修复 1.3.0.0 的 Linux Java + AI 链接问题，并补齐 Java 安装后验证。

- 修复源码构建的静态 libharu 未启用 PIC，导致 Linux 上无法链接 Java + AI JNI 动态库的问题。
- 增加独立 Java 安装消费者：仅引用安装后的 JAR，并将 JNI 搜索路径限定为安装目录。
- 分别验证不带 AI、带 AI 两种配置，强制检查 AI 类是否与构建配置一致，避免缺少 AI 时静默跳过。
- 安装后测试覆盖四种 DAT、CFF/HDR、工程量和流式时间；AI 模式额外覆盖摘要、完整波形、
  本地模拟 HTTP 模型请求/响应及中文 PDF 导出，不调用外部模型。
- 增加 `Java` 安装组件，可通过 `cmake --install <build> --component Java --prefix <prefix>`
  单独安装 JAR/JNI，并更新 README 和复现说明。
- CI 为普通 Java 和 Java + AI 分别执行构建、安装、独立消费者编译和运行，保留 JUnit 报告。
- 在原有四个平台的 C++ 核心与 AI 安装包之外，增加两份经过安装测试的 Linux Java 安装包。

保留 1.3.0.0 的 CFF、时间轴与时区、缺失值、容错警告和 DAT 厂家尾部支持。
Java 的两份 Linux 包分别使用 JAR 和本地 JNI 库；运行时需要匹配的 JDK、C++ 运行库，
AI 包还需要 OpenSSL 3.x，PDF 使用者需自行提供有许可的字体。它们不是跨系统的通用二进制包。
Windows Java 本地安装测试和 Linux Java CI 已验证；本次不提供 Windows/macOS Java 预编译包。

完整 CI（含 C++ 核心/AI 安装消费者、OpenSSL 源码回退和两种 Java 安装消费者）全部通过后才发布。

## 直接下载 JAR

- `comtrade-core-java-1.3.0.1.jar`：普通 Java API，不包含 AI 类。
- `comtrade-core-java-ai-1.3.0.1.jar`：包含核心及 AI API；与普通版二选一，不要同时放入 classpath。

两份 JAR 均来自对应 Linux CI 安装后测试通过的产物。它们不内嵌 JNI 动态库，不能只依靠 JAR 独立运行。
Linux 请同时下载对应 `ComtradeCore-java-linux` / `ComtradeCore-java-ai-linux` 安装包，
将其 `lib/comtrade/java` 配置到 `java.library.path`。其他系统需要自行构建匹配的 JNI 库。
JDK 应与发布产物的 Java 字节码版本匹配；AI 还需匹配的 OpenSSL 3.x，PDF 需要自行提供字体。

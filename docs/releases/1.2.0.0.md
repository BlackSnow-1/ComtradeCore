# ComtradeCore 1.2.0.0

- AI 功能改为独立 C++17 模块，移除 Java AI 模块，无 Qt/JVM 依赖。
- 可选 `COMTRADE_BUILD_AI`，核心 header-only 库及原有 Java 解析绑定保持独立。
- 四种 DAT 的工程量摘要、触发前后统计、完整波形模式、Chat Completions HTTP/TLS 与中文 PDF。
- 使用 cpp-httplib/OpenSSL、nlohmann/json 和 libharu，凭据通过环境变量配置。
- C++ 单元测试、本地模型服务集成测试、中文 PDF 校验和安装包消费者测试接入多平台 CI。
- Release 在所有 CI 作业成功后发布已测试的核心与 AI 安装包。

使用方法、依赖和限制见 `docs/ai-analysis.md`。AI 包需匹配平台编译器及 OpenSSL 3.x；字体需自行提供。

## 本次重新发布的改动

- AI 模块改为真正的 header-only 实现：`analysis/cpp/{include,src}` 下的 `.cpp`/`ai.hpp` 全部移除，
  逻辑迁移到 `include/comtrade/ai.hpp` + `include/comtrade/ai/{config,statistics,evidence,client,
  pdf,detail}.hpp`，与核心 COMTRADE 读写实现物理分开在独立子目录，`analysis/cpp` 现在只保留依赖获取
  的 CMake 脚本和 `comtrade-ai` CLI。
- 新增独立的安装开关 `COMTRADE_INSTALL_AI`（默认开）：可以只本地构建、测试 AI 模块而不将其纳入
  `cmake --install`，与是否构建（`COMTRADE_BUILD_AI`）完全解耦。
- 三个第三方依赖（nlohmann/json、cpp-httplib、libharu）改为"先在本机 `find_package`/`find_library`
  查找，找不到再 `FetchContent` 拉取固定版本"，其中 libharu 的本机查找额外校验版本必须是 2.4.x
  （因为 PDF 渲染依赖其 2.4.x 内部字体结构布局，跨大版本不保证 ABI 兼容）。
- `Config` 新增 `fromFile()`，`find_package(ComtradeCore COMPONENTS AI)` 新增
  `ComtradeCore_AI_CONFIG_EXAMPLE` 变量，方便下游项目直接复制安装好的示例配置。
- `comtrade::StreamReader` 的 `SampleRow` 新增 `segment_index`/`segment_sample_rate` 两个字段，
  让多段不同采样率（IEEE C37.111-2013 `nrates=0` 后跟任意数量采样段）的录波在流式回调里能直接判断
  当前点属于哪一段、这段标称多少赫兹，定位代价为 O(采样段数)、不随采样点数增长。
- 新增 Java 接口 `comtrade.ComtradeAI`：只在 `BUILD_JAVA_BINDINGS` 与 `COMTRADE_BUILD_AI` 同时打开
  时随 `comtrade-core-java.jar` 一起构建，方法均以 JSON 字符串收发，不需要额外的类型映射。
- AI 单元测试迁移到顶层 `tests/test_ai.cpp`，构建为独立的 `comtrade_ai_tests` 可执行文件，与核心
  `comtrade_unit_tests` 完全解耦；`tests/verify_pdf.py` 承接原有的 Poppler 中文 PDF 校验。

# ComtradeCore 1.2.0.0

- AI 功能改为独立 C++17 模块，移除 Java AI 模块，无 Qt/JVM 依赖。
- 可选 `COMTRADE_BUILD_AI`，核心 header-only 库及原有 Java 解析绑定保持独立。
- 四种 DAT 的工程量摘要、触发前后统计、完整波形模式、Chat Completions HTTP/TLS 与中文 PDF。
- 使用 cpp-httplib/OpenSSL、nlohmann/json 和 libharu，凭据通过环境变量配置。
- C++ 单元测试、本地模型服务集成测试、中文 PDF 校验和安装包消费者测试接入多平台 CI。
- Release 在所有 CI 作业成功后发布已测试的核心与 AI 安装包。

使用方法、依赖和限制见 `docs/ai-analysis.md`。AI 包需匹配平台编译器及 OpenSSL 3.x；字体需自行提供。

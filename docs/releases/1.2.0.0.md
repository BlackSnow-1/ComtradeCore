# ComtradeCore 1.2.0.0

- 新增可选 Java 17+ AI 录波分析模块 `comtrade-ai-java`，复用 JNI 流式解析四种 DAT 格式。
- 新增模型 URL、环境变量 token、自定义请求参数、请求头、超时及大小限制配置模板。
- 本地计算样本加权 RMS、峰值及时间、分段摘要、开关量变位和数据质量标记；发送有界摘要。
- PDF 包含文件 SHA-256、本地证据与独立标注的模型分析，支持 Unicode TTF 字体和自动分页。
- CI 新增摘要统计、模拟 HTTP、实际 JNI 四格式往返和 PDF 导出测试；Release 工作流依赖全部 CI 作业成功。

AI 模块为独立 Maven 构件，不改变 C++ header-only 核心依赖。模型输出属于待人工复核的辅助意见。
发布附件中的 Java JNI 动态库为 Linux x86_64；Windows/macOS JNI 请按 README 在目标平台构建。
JAR 不包含第三方 Maven 依赖或字体，需按文档安装 POM 并提供具有目标语言字形的 TTF 字体。

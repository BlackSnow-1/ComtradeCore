# ComtradeCore 1.3.0.2

- 新增 IEEE C37.111 CFG/DAT 检查工具。Release 提供 Windows x86-64 EXE 和 Linux x86-64 tar.gz，核心安装包通过 `bin/comtrade-check` 提供同一工具。
- 读取 CFG、DAT 和 CFF 时记录格式警告。C++ 调用方可通过 `ReadOptions::warning_logger` 接入应用日志，通过 `getWarnings()` 获取诊断。
- 统一处理各版 ASCII 缺失值。1991 使用 `999999`、1999 使用 `99999`、2013 使用空字段。1991、2013 写出规定的 ASCII EOF 标记。
- 新增各版布局、文本和二进制边界、交叉检查及日志回归测试。

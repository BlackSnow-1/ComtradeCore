# ComtradeCore 1.3.0.0

本版在 1.2.0.0 基础上增加文件支持、容错诊断及使用示例。

- 增加 CFF 单文件读写与流式读取，支持 ASCII、BINARY、BINARY32、FLOAT32 数据以及 HDR/INF 文本。
- 增加时间轴策略：按 DAT 时间戳、按采样率重建、自动选择；保留纳秒精度并处理 2013 UTC 偏移。
- 增加缺失模拟量标记与 NaN 处理、坏行恢复、残缺二进制记录和时间异常的聚合警告。
- 增加 DAT 厂家尾部隔离、预览大小限制、分块回调、导出及显式复制；不解释私有格式、不重算厂家校验码。
- 统一 CFG 数字字段校验：拒绝静默数字前缀和整数截断，可选元数据出错时使用默认值并警告；
  补充数字通道编号、额外字段、本地时间码检查。无法可靠确定布局、换算系数或日期时仍失败。
- 增加 Java 对 CFF、读取策略、警告和厂家尾部的接口；AI 证据包含数据质量警告并排除厂家尾部字节。
- 增加 C++ / Java 示例，覆盖四种数据编码、CFF、多段时间轴、缺失值、厂家尾部、真实文件检查和离线 AI。
- OpenSSL 改为本地开发文件优先，缺失时从官方 GitHub 下载固定版本并校验、构建；保留离线与路径覆盖选项。
- 补充字段校验回归测试及文档，修正 README 对零时间戳重建策略的过时说明。

闰秒和通道 skew 仍仅作为元数据报告，不自动校正；未知时区会警告并沿用本机时区。
AI 相量、谐波和故障测距不在本版实现范围内。

本地验证：61 项核心单元测试、8 项真实录波准确性测试、17 项 AI/HTTP/PDF 测试通过。
Release 工作流在多平台 CI 及 OpenSSL 源码回退检查全部通过后发布已测试的核心和 AI 安装包。

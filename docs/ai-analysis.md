# AI 录波分析设计与使用边界

`analysis/java` 是可选 Maven 模块，Java 17+，通过 `ComtradeStreamReader` 复用 C++ 解析器。
HTTP、JSON 和 PDF 依赖留在该模块中，不增加 C++ 核心或基础 Java JAR 的依赖。

## 数据处理

1. 对 CFG/DAT 计算 SHA-256，解析完成后重新计算，发现输入变化则拒绝分析；调用方应提供不再写入的文件快照。
2. 按 CFG 自动流式读取 ASCII/BINARY/BINARY32/FLOAT32。回调值已完成 `raw*a+b` 工程量换算，不再次乘 CT/PT 比例。
3. 每个模拟量累计有限值计数、最小/最大值及其纳秒偏移、均值、样本加权 RMS。采用缩放平方和，避免大有限数平方溢出。
   另按 CFG 触发时间累计触发前/触发起两组统计；触发时刻不一定是故障起始，不能把触发前直接判定为正常基线。通道 skew 仅报告，不做时间补偿。
4. 默认以 20 ms 建立时间窗口；达到窗口上限时合并相邻窗口，保留极值和统计量。20 ms 是可配置摘要窗口，不能当作已识别的电网周期。长录波后期窗口会变粗，不是均匀抽样波形。
5. 数字量保留初始/最终状态、各通道变位总数及前 N 条变位事件；超出上限的数量明确写入证据。事件时间是采样时刻，不插值推断真实开关动作时刻。
6. 元数据包含相别、单位、CT/PT、P/S、skew、采样率段、开始/触发时间和时区质量。默认隐藏站点、设备和通道名称，以 A1/D1 等位置标识引用。
7. 采样序号断续、非递增时间、非有限值、CFG/DAT 数量不符以及事件截断均显式记录。解析器只回调有效行，因此摘要不能证明原文件无坏行或无尾部残缺。

摘要内存随 `通道数 × maxWindows + maxDigitalEvents` 增长，不随采样点数增长；JNI 每行仍有短期数组分配。
超过 `maxChannels` 直接拒绝，不静默丢弃通道。HTTP 按序列化后的 UTF-8 字节检查 `maxRequestBytes`，超限不发送、不静默截断。
字节上限不是精确 token 预算，应根据模型上下文和输出预算调小。当前不进行自动分批模型调用或额外计费重试。

RMS 定义为 `sqrt(sum(x²)/N)`，包含直流分量，不是基波 RMS；变采样率情况下是样本加权而非时间加权。
尚未实现相量、频率、谐波、序分量、故障测距和保护定值判据；峰值/RMS 不能替代这些算法。
DAT 时间戳按 TIMEMULT 换算。全零时间戳不自动按采样率重建，因此此类文件的事件时序不可靠，会产生质量标记。
波形的高频细节和瞬态形状可能在窗口合并后丢失；重要结论必须返回原始录波人工复核。

## 模型与凭据

配置模板为 `config/ai-config.example.json`。复制到 Git 忽略的 `ai-config.json`，填写完整的
Chat Completions endpoint（不是网站首页）、模型 ID、请求参数和字体路径。
优先从 `tokenEnv` 指定的环境变量取 token，变量为空时回退到 `token` 字段。不要把真实凭据填入已跟踪的模板。
`headers` 可添加供应商要求的请求头；Authorization/Content-Type 等保留头不能覆盖。
`requestParameters` 支持 `temperature`、`max_tokens` 等供应商参数；model/messages/stream/tools 等保留字段不能覆盖。
未知供应商参数会原样传递，调用方应按自己的服务文档配置。其他协议通过实现 `ModelClient` 接入。

调用 `summarize` 完全在本地处理；调用 `analyze` 才向配置 endpoint 发送摘要。
默认隐藏标识不等于完全匿名，时间、相别、单位、统计值仍会发送。发送前应确认所用服务可接收这类录波数据。
仅允许 HTTPS；显式启用 `allowInsecureLocalhost` 后可使用 localhost HTTP 做本地模型或测试。
不跟随重定向、不自动重试、不输出服务器错误正文；超时包括响应正文接收，响应字节数受限。
模型返回的截断、工具调用或无内容响应视为失败。模型文字仅作为文本渲染，不执行其 HTML、链接或指令。

## PDF 与可追溯性

报告分为本地测量事实、未验证的模型解释、完整摘要附录，包含创建时间、模型 ID、原文件哈希与质量说明。
不会写入 token、请求头或 endpoint。字体由 `pdfFontPath` 提供，支持 TTF 和 TTC（选首个字体）；中文需要包含中文字形的字体。
Linux 可安装 `fonts-wqy-microhei`，使用 `/usr/share/fonts/truetype/wqy/wqy-microhei.ttc`。
缺失字形会报错而不是悄悄把中文替换为乱码。采用文字宽度换行、自动分页和嵌入字体。
目标目录须事先存在；已有 PDF 不覆盖；失败时清理临时 PDF。
字体许可由使用者确认；本项目不捆绑系统字体。报告属于辅助研判，不是自动保护控制或已认证的故障诊断。

## 测试与发布

CI 构建真正的 JNI 库和 JAR，在四种 DAT 上测试读取及缩放，使用本地 HTTP 模拟模型响应，不需要真实 token。
单元测试覆盖 RMS、峰值时间、窗口合并、事件限长、异常时间、缺失文件、请求配置、超时、错误响应、中文 PDF 字形、分页和文本提取。
Release 工作流复用完整 CI；所有 C++ 平台矩阵与 Java AI 作业成功后，才创建版本标签和发布已测试附件。
